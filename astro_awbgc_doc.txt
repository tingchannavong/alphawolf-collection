DOCUMENTATION FOR ALPHA WOLF ASTRO SITE:

STEPS SET UP ASTRO PROJECT IN NEW COMPUTER >>
In root:
	1. download nvm: node version manager
	2. download node.js
	3.  DONE!

In project folder:
	1. npm install
	2. create venv: python3 -m venv venv
	3. activate venv
		In mac: source venv/bin/activate
		In wins: .venv\Scripts\activate
	4. pip install EZSHEETS dotenv
	5. DONE! Command to exit virtual environment: deactivate

STEPS TO AUTHORIZE EZSHEETS:
	1. Enable API of Google sheet && google drive in google cloud console
		- https://console.developers.google.com/apis/library/sheets.googleapis.com/
		- https://console.developers.google.com/apis/library/drive.googleapis.com/
	2. If re-authorize, delete credentials.json, & 2 pickle files
	3. In existing google cloud project Ex: BGG-Geek (or new), click API & services tab and then click OAuth consent.
		Manage OAuth consent below: 
	4. Go to Branding page & create app for external audience.
	5. Go to Audience page, add test user's email.
	6. Go to clients, create (+) OAuth client ID for DESKTOP APP & download json file.
	7. Copy json file to put in your root project folder and rename as "credentials-sheet.json".
	8. Add redirect URIs:
	  - http://127.0.0.1:8080/
	  - http://localhost:8080/
	9. Run the python project & log in to ur google account when prompted, this will auto create the 2 new pickle files.
	10. DONE!
